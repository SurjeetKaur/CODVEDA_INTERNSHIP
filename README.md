# CODVEDA Internship Projects

## About This Repository

This repository contains the projects completed as part of my Full-Stack Development Internship at CODVEDA Technology.

The repository includes six tasks across three levels, covering development environment setup, frontend development, React, authentication, full-stack application development, and real-time communication.

The projects are organized by level to maintain a clear structure and demonstrate practical software development skills.

## Level 1 — Basic

### Task 1: Setup Development Environment

**Completed activities:**

- Set up Visual Studio Code.
- Installed and configured Git and GitHub.
- Installed a database environment.
- Practiced basic terminal commands and Git operations.

**Technologies:** Node.js, npm, VS Code, Git, GitHub, MongoDB.

### Task 3: Frontend with HTML, CSS, and JavaScript

**Project:** Taskflow — Employee Task Dashboard

**Objective:** Build a responsive frontend that interacts with a REST API and displays task data dynamically.

**Key features:**
- Employee task dashboard interface.
- Dynamic task data rendering.
- API integration using the Fetch API.
- Responsive layout and CSS styling.
- API testing using Postman.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/SurjeetKaur/CODVEDA_INTERNSHIP.git
```

### 2. Open the Repository

```bash
cd CODVEDA_INTERNSHIP
code .
```

### 3. Navigate to a Project

For example:

```bash
cd LEVEL3_TASK1_FULL_STACK_MERN_TASKFLOW
```

Replace the folder name with the task you want to run.

### 4. Install Dependencies

Navigate to the appropriate project or frontend/backend folder containing `package.json` and run:

```bash
npm install
```

### 5. Run the Project

Follow the instructions in the individual project's README file. Full-stack applications may require the frontend and backend servers to run separately, along with the database.
