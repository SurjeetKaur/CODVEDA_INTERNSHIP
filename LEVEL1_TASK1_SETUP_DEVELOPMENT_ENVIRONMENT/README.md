# Task 1: Setup Development Environment

## Overview
Successfully set up a full-stack development environment by installing and configuring essential development tools. This task involved setting up Node.js, npm, Visual Studio Code, Git, GitHub, and MongoDB, along with learning basic terminal commands and version control operations.

## Tools Installed and Configured

- **Node.js** – JavaScript runtime environment for running JavaScript outside the browser.
- **npm** – Package manager for installing and managing JavaScript dependencies.
- **Visual Studio Code** – Code editor for writing and managing code.
- **Git** – Version control system for tracking changes and managing source code.
- **GitHub** – Online platform for hosting repositories and collaborating on code.
- **MongoDB** – NoSQL database for storing and managing application data.
- **Terminal** – Used to execute commands and manage files and directories.

## Tasks Completed

### 1. Node.js and npm Setup
- Installed Node.js and npm.
- Verified the installations using version commands.
- Learned how npm manages project dependencies.

### 2. Git and GitHub Setup
- Installed and configured Git.
- Set up a GitHub repository.
- Practiced basic Git commands for tracking and managing code changes.
- Learned how to stage, commit, and push changes to GitHub.

### 3. Database Setup
- Installed and configured MongoDB.
- Learned the basics of database installation, connection, and data storage.

### 4. Terminal Commands
Practiced basic terminal commands for navigating directories, creating folders, listing files, and managing development tasks.

Commands practiced include:


node -v
npm -v
git --version
git status
git add .
git commit -m "Initial commit"
git push
mkdir folder-name
cd folder-name
cd ..

- Gained practical experience in setting up a full-stack development environment.
- Understood the roles of Node.js and npm in JavaScript development.
- Learned basic Git and GitHub version control workflows.
- Installed and configured MongoDB for database management.
- Improved familiarity with terminal commands and directory navigation.

## Conclusion

Successfully completed the development environment setup task and configured the essential tools required for full-stack web development. This setup provides a foundation for developing, testing, and managing future web applications.
