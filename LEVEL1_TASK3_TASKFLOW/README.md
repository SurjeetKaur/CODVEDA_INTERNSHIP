# TaskFlow - Employee Task Dashboard

TaskFlow is a simple and responsive Employee Task Dashboard built as part of an internship frontend/API integration task.

The project demonstrates how a frontend website can fetch data from a REST API using JavaScript Fetch API and display the data dynamically on the webpage.

## Features

- Responsive employee task dashboard
- REST API integration
- Fetch API for retrieving data
- Dynamic task table
- Task summary statistics
- Task status and priority badges
- Recent activity section
- Refresh data functionality
- Loading state
- API error handling
- Responsive design for desktop and mobile
- API can be tested using Postman

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- JSON Server
- REST API
- Postman
- Git & GitHub
